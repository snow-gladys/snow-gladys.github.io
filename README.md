# www.snow-gladys.com

小心思胡乱做的网站qwq

致歉一切！

播放器统一在主页。左上角可以换装扮，歌单里可以整理自己想听的歌；换装扮不会切歌。

原来的思诺、心宜精选与 Live 歌库分别保留为预置歌单。心宜数据文件已移到 `catalogs/`，旧 `/fiona/` 入口由 `404.html` 跳转到主页。

自建歌单、收藏和播放记录保存在当前设备。头像在本机裁剪压缩，使用 IndexedDB 保存，每位最多一张、每张最多 512 KB；原图不上传。桌面图标不随装扮或上传头像改变。

`personal-library.js` 负责歌单存储与旧数据迁移，`library-ui.js` 对接歌单界面和播放范围，`wardrobe.js` 负责装扮与头像。默认成员图来源见 [图像说明](imgs/wardrobe/SOURCES.md)，安卓构建见 [安装包说明](android-app/README.md)。

验证：`node --test tests/*.test.mjs`。

手机播放页频谱由 `mobile-visualizer.js` 绘制：最多 48 根柱子、24 帧、1.5 倍像素密度，安卓使用 512 点 FFT。iOS 保留原生音频链路，使用随播放启停的装饰动画，不代表真实频谱，避免 HLS 在 Web Audio 中缺少样本或影响声音。动画不会额外请求或解码歌曲；暂停、离开播放页、后台和“减少动态效果”均停止绘制。电脑频谱与小窗保留原来的样式。

添加歌曲支持 BV 号、完整视频链接或含 b23.tv 短链的分享内容，自动填入的视频标题可修改；自建歌单的“添加歌曲”中也有粘贴入口。需要同步部署 [完整边缘函数](edge-functions/bilibili.js) 中新增的 `/info` 接口（标题查询与短链解析）；旧函数仍可播放，自动填名不可用时可填写 BV 和歌名后手动添加。

当前头像会生成一张临时方形 JPEG 交给 Media Session，供锁屏、控制中心和灵动岛作为播放封面使用；头像仍保存在本机，手机主屏幕上的安装图标不受影响。

`playback-ui.js` 负责进度条：前台按帧更新，拖动时合并预览、松手只跳转一次，支持触摸、鼠标、键盘和取消手势。缓冲检查与进度保存继续走音频事件；初始音频只绑定一套稳定监听。歌词节点和歌单数据按版本复用，搜索合并到下一帧，弹层遮挡时暂停背景绘制。移动端底栏通过自动外边距居中，避免改变固定歌名的定位参照。
