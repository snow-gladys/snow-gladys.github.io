# 思诺 · Gladys 安卓试用版

安装包加载 `https://www.snow-gladys.com/`，沿用网站的思诺／心宜切换和界面。网站更新后，重新打开页面即可获取更新；安卓壳本身的修改需要重新安装 APK。

支持 Android 8.0 及以上。已接入系统返回键、文件选择与歌词／歌曲列表导出、网络错误重试，以及通知栏和锁屏播放控制。音频仍由 Android System WebView 播放。后台服务在播放期间运行，暂停五分钟后退出；从最近任务中划掉应用会结束播放。锁屏连续播放、耳机控制和各手机的省电限制仍需真机验证。

## 构建

使用 JDK 21、Android SDK 的 `platforms;android-36` 和 `build-tools;36.0.0`。无额外依赖，不需要 Gradle。这个目录是命令行构建工程。

```sh
python3 android-app/build.py --sdk /path/to/android-sdk
```

也可以设置 `ANDROID_HOME`／`ANDROID_SDK_ROOT`，或将 SDK 放到项目下 `.android-local/sdk`，然后省略 `--sdk`。

输出为 `android-app/build/gladys-player-0.1.0.apk`，附有 SHA-256 文件；脚本完成签名、签名验证及安装包对齐检查。

第一次构建会生成个人分发用签名，存放在 `.android-local/signing/`。请妥善备份整个目录，后续版本必须沿用这份签名才能覆盖安装。签名文件、密码、SDK 和编译产物均已排除在 Git 之外。版本号及版本代码在 `AndroidManifest.xml`，升级时同步更新构建脚本里的输出文件名和 MainActivity 的客户端版本。

## 使用

将 APK 发到安卓手机，打开后按系统提示允许本次安装。应用首次启动需要联网；网页缓存能力沿用现有播放器。应用和浏览器的收藏、歌词调整及缓存分别存储，已有浏览器数据不会自动迁移。

网页已经补齐思诺与心宜各自的主屏幕图标及清单。部署网页改动后，iPhone 可在 Safari 打开对应页面，使用「分享 → 添加到主屏幕」；这个方式不需要安装 IPA。

## 发布前真机检查

- 首次加载及思诺／心宜切换；断网重试、返回键关闭弹窗并返回首页。
- 播放、连续切歌和预加载切换；锁屏十分钟、通知栏／耳机播放控制，以及来电后的音频行为。
- 歌曲列表与 LRC 文件导入导出；收藏与已缓存歌曲在重启后保留。

当前提供个人试用版。系统回收网页进程时播放会停止；若需要更强的后台播放保证，后续需将音频引擎迁到原生播放器。
